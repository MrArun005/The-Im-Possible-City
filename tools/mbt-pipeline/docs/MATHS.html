Every equation that actually ran during the build — the solid constructor, two renderers written from nothing, the radiometry that was wrong twice, and the topology proof that the mesh is watertight.

01

Solid construction

Every part is a convex solid swept from a 2D profile. For a profile {(uₕ, vₕ)} extruded along an axis of length L with a taper k applied at the far cap, the vertex map for axis x is:

Aₕ = ( −L/2 , vₕ , uₕ ) Bₕ = ( +L/2 , k·vₕ , k·uₕ )
1.1

Caps are fans over each ring; sides are quads (Aₕ, Aⱼ, Bⱼ, Bₕ) with j = (i+1) mod n. A cylinder is the same routine with a circular profile, and its side normals are radial rather than face-derived — that single distinction is what makes 22-segment barrels read as round instead of faceted:

nₕ = ( 0 , vₕ , uₕ ) / √(uₕ² + vₕ²)
1.2

Chamfering a profile

Sharp profile corners were bevelled analytically before extrusion. Each vertex p with neighbours a, b becomes two vertices pulled a distance c along each incident edge:

p₁ = p + c · (a − p)/|a − p| p₂ = p + c · (b − p)/|b − p|
1.3

Orienting normals without trusting winding

Winding was inconsistent across my face tables, so backface culling failed and box interiors showed through. Rather than fix 12 face orderings by hand, normals were oriented against each solid's own centroid C — valid for any convex solid:

n ← n · sgn( n · (cᵤ − C) ) cᵤ = triangle centroid
1.4

Track as an arc-length path

The track is a stadium curve of straight length L and end radius r, sampled at constant arc length so link pitch stays uniform around the sprocket:

P = 2L + 2πr θ(t) = −atan2( Δy , Δz ) link pitch = P / N , N = 84 per side
1.5

The wheel-overlap bug, as inequalities

You spotted road wheels passing through each other. The whole defect is one inequality that was never checked. For equal circles of radius r at pitch s, and for two circles of radii r₁, r₂ at centre distance d:

neighbours: s − 2r ≥ 0 dissimilar: d − (r₁+r₂) ≥ 0 d = √(Δz² + Δy²)

03

Rasteriser written from nothing

Before Blender was available, the renderer was a z-buffer rasteriser in numpy. Camera basis from eye e, target t, world up u:

f = (t − e)/|t − e| , r = (f × u)/|f × u| , u′ = r × f fl = (H/2) / tan(fovᵛ/2) sₓ = W/2 + xᵛ·fl/z , sᵡ = H/2 − yᵛ·fl/z
3.1

Coverage via edge functions, with D twice the signed screen area:

D = (x₁−x₀)(y₂−y₀) − (x₂−x₀)(y₁−y₀) w₀ = [ (x₁−pₓ)(y₂−p₁) − (x₂−pₓ)(y₁−p₁) ] / D inside ⇔ w₀,w₁,w₂ ≥ 0
3.2

Depth is stored as 1/z, because 1/z is affine in screen space while z is not. The same fact gives perspective-correct attributes — world position and normals are interpolated as A/z then divided by the interpolated 1/z:

1/z = Σ wₕ/zₕ A = ( Σ wₕ·Aₕ/zₕ ) / ( Σ wₕ/zₕ )
3.3
Bug — the ground was one enormous quad

A single 520 m ground quad had two corners behind the camera, where zview < 0. Equation 3.1 divides by z, so those vertices projected through infinity and every barycentric weight on that triangle was garbage. World position was therefore garbage for every ground pixel — which silently broke the shadow lookup, the ambient occlusion and the soil texture at once, from one root cause. Fix: reject any triangle with min zᵛ ≤ n and tessellate the ground into camera-centred rings so no triangle ever straddles the near plane.

04

Shadow mapping, and why the test is exact

Build an orthonormal light basis from the sun direction L (pointing toward the light), then store, per light-space cell, the depth of the closest surface:

lᵘ = (L × up)/|L × up| , lᵛ = lᵘ × L u = P · lᵘ , v = P · lᵛ , d(P) = C − P · L
4.1

A point is lit iff d(P) ≤ dmap(u,v) + β. This is exact, and the proof is two lines. Any occluder lies at Q = P + tL for some t > 0. Since lu, lv ⊥ L, occluder and receiver share the same (u, v) cell, and:

d(Q) = C − (P + tL)·L = d(P) − t ⇒ d(P) = d(Q) + t > d(Q) + β for t > β
4.2

So the receiver fails the test by exactly the distance to its occluder. Bias must be slope-scaled or grazing surfaces self-shadow into acne; nine taps give ten discrete shadow levels:

β = β₀ + β₁(1 − n·L) = 0.013 + 0.052(1 − n·L) PCF: mean of 3×3 binary tests → {0, 1/9, …, 1}
4.3
05

Radiometry — the error that whitened everything

Lambertian radiance from irradiance E at incidence θ, albedo ρ:

L = ρ · E · cosθ / π
5.1

The first renders came out near-white. The cause: I authored paint colours as sRGB display values and fed them straight in as ρ. Light transport is linear, so albedo must be decoded first:

ρₗⁱₙ = ρₛᵣᵤᵇᵇ^2.2
5.2

The second radiometric error was scale. Blender's physical sky delivers real daylight, roughly E ≈ πL̄ ≈ 50 W/m² of diffuse irradiance, while my sun lamp was set to 5.2 W/m². The sun was contributing under a tenth of the light, so the image was pure ambient — flat and shadowless. Real direct normal irradiance is ~950 W/m²:

ΔEV = log₂(Eₖᵉₛ/E₋ₗₐ) = log₂(950/5.2) = 7.51 stops
5.3

That predicted exposure shift is why the working exposure landed at −5.95 EV rather than the +0.35 I began with — a 6.3-stop move, the remainder absorbed by the sky term that had been dominating.

06

Where to put the sun

Shadows kept hiding behind the tank. That is not an art problem, it is a dot product. A point at height h casts to a ground offset along −Lh, the horizontal part of the sun vector:

shadow offset = −Lₕ · h / Lᵡ |Lₕ|/Lᵡ = 0.630/0.776 = 0.812 m per m of height
6.1

Visibility of that offset depends on its angle to the view direction v̂. With the sun behind the camera, Lh ∥ v̂, the shadow runs directly away from the viewer and the subject occludes its own shadow. Maximum visibility is the perpendicular case:

Lₕ · v̂ ≈ 0 ⇒ shadow sweeps across frame, fully visible
6.2

But that condition puts every camera-facing surface at grazing incidence — lit faces go dark. Both goals are satisfiable at once by aiming the subject, not the light. Choose the heading f as the bisector of the sun and camera azimuths:

f = (Lₕ + c)/|Lₕ + c| with Lₕ·c = 0 , both unit |Lₕ + c| = √(2 + 2Lₕ·c) = √2 f·Lₕ = f·c = 1/√2 = cos 45°
6.3
Result

The glacis and the flank each sit at exactly 45° to both sun and camera — front lit, flank in grazing light for form, and the cast shadow still perpendicular to the view. For this scene that heading is 84.3°, and it is computed, not eyeballed.

07

Reflectance model

Specular uses GGX / Trowbridge-Reitz with α = roughness², Smith-Schlick geometry and Schlick's Fresnel:

D = α² / ( π [ (n·h)²(α² − 1) + 1 ]² ) G = (n·l)/((n·l)(1−k)+k) · (n·v)/((n·v)(1−k)+k) , k = α/2 F = F₀ + (1 − F₀)(1 − n·v)⁵ fᵣᵔᵉᶜ = D·G·F / (4 (n·l)(n·v))
7.1

Ambient in the hand-written renderer is a two-lobe hemisphere — sky above, ground bounce below — mixed by the normal's vertical component:

Lᵤᵐᵇ = ρ [ Sᵘᵗ · ½(1 + nᵡ) + Sᵏₙ · ½(1 − nᵡ) ] · AO
7.2
08

Procedural fields

All surface variation is value noise on an integer lattice, hashed and interpolated with the smoothstep basis, summed over octaves:

w(t) = 3t² − 2t³ noise(x) = trilerp over 8 lattice hashes, weights w(frac x) fBm(x) = Σₖ aᵏ · noise(bᵏ x)
8.1

Why the camouflage needed one octave, not four

Camo is hard thresholds on the noise value. If n ~ U(0,1), the cut points are the area fractions — so the pattern mix is specified directly:

green n < 0.445 44.5% brown 0.445 ≤ n < 0.715 27.0% black n ≥ 0.715 28.5%
8.2

Summing octaves breaks this. By the central limit theorem a sum of independent noise terms tends to Gaussian, the distribution concentrates about the mean, and the tails thin out — so the upper cut stops being reached and the black patches disappear. That is exactly what the four-octave version rendered, and it is why the final pattern uses one octave plus a small perturbation.

Dust saturation

Dust accumulates by height and surface angle. The first version clipped to 1 across the entire lower hull, repainting it uniform brown:

d = clamp( h(y) · max(0, n·û) · noise · k , 0, 1 ) k = 1.56 → d ≡ 1 over most of the hull k = 0.63 → usable gradient
8.3
09

Display transform

Scene-linear radiance is exposed, tone mapped through the ACES-style rational approximation, then gamma encoded:

x ← L · 2^EV x′ = x(2.51x + 0.03) / ( x(2.43x + 0.59) + 0.14 ) c = clamp(x′,0,1)^(1/2.2)
9.1

The rational form matters: it is monotonic, has a soft shoulder that compresses highlights instead of clipping them, and rolls off toward 1 asymptotically. A naive clamp would have blown out the sunlit deck.

10

Rig transforms — and the exploded tank

Moving a part's origin to its rotation axis must not move the part. Subtract the pivot from the mesh and put it back as a translation — the world position is invariant:

v′ = v − p , M = T(p) M · v′ = v ✓
10.1

Parenting then has to preserve world transforms. Blender composes:

Mᶠₜₜₛₔ = Mₚₐₕₑₐₘ · Mₚⁱ · Mₗₒᶜₐₗ ⇒ Mₚⁱ = Mₚₐₕₑₐₘ⁻¹
10.2
Bug — stale parent matrix

I read Mₚₐₕₑₐₘ before the dependency graph had refreshed, so it returned the identity while the parent had actually been translated to its centroid. With Mpi = I instead of T(p)−1, every child inherited an unwanted offset of exactly pparent — the turret floating above a hull that had come apart. It went unnoticed for one stage only because Hull's pivot happened to be the origin, making T(0) = I and the bug invisible.

Axis conversion

The generator works Y-up, Blender is Z-up. The mapping must be a proper rotation, or the model mirrors:

(x, y, z) → (x, −z, y) det = +1 ✓ handedness preserved
10.3

Utilisation is bounded by island count, not by the packer. Each island carries a margin, so wasted area grows with total island perimeter — roughly N·√Ā·m. 3,756 islands against a single-island control that reaches 50.8% at identical settings isolates the cause to the mesh being 626 intersecting shells.

Bug — island detection compared the wrong corners

Two faces sharing an edge traverse it in opposite orientation. Comparing each face's edge-loop UVs positionally compares the UV at one face's first vertex against the other face's second — almost never equal, so every face read as its own island and the count came back as 14,432, exactly the face count. Continuity has to be tested per vertex:

continuous ⇔ { (v, uv) : v ∈ edge }ᶜ = { (v, uv) : v ∈ edge }ᶫ
11.2
12

Topology, proved

The strongest result in the build needs no renderer. In a closed triangle mesh every edge is shared by exactly two faces, which pins the edge count from the face count:

E = 3F/2 = 3(14,432)/2 = 21,648
12.1

Euler's formula for a disjoint union of c closed orientable surfaces of genus gₕ:

χ = V − E + F = Σₕ (2 − 2gₕ)
12.2
χ = 8,468 − 21,648 + 14,432 = 1,252 if every shell is genus 0: c = χ/2 = 626
12.3
Independent confirmation

The connected-component count measured by flood fill is 626. It agrees with χ/2 exactly. Two unrelated methods — one combinatorial, one a graph traversal — return the same number, which proves all 626 shells are closed, orientable and genus 0: no holes, no handles, no boundary. The measured counts of non-manifold edges, boundary edges, loose vertices, zero-area faces and duplicate faces are all 0, consistent with that.

This is the one respect in which the asset is genuinely production-grade, and it is the criterion most hand-modelled meshes fail.
